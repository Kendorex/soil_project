# APSIM Next Generation + NSGA-II

Версия 2026.10.16-humic. Основная задача — управление культурами на фиксированной
карте 10 полей за 2020–2023 годы. 2018–2019 годы формируют начальное состояние.

## Что оптимизируется

- Максимум собранной сухой массы.
- Максимум расчётного экономического результата.
- Минимум дефицита остаточного минерального N относительно базового расчёта.

**Включено жёсткое ограничение:** конечный запас модельного углерода Humic
должен быть не ниже собственного начального на каждом поле.
Проверяется весь профиль 0–180 см, конец 31.12.2019 → конец 31.12.2023.
Потеря на одном поле делает вариант недопустимым. Прирост на другом её не
компенсирует; отсутствие проверенных данных не считается прохождением.
Ограничение учитывается при отборе NSGA-II и формировании итогового Парето.
Азот остаётся мягкой целью. Отключение: в
`configs/multiyear_rotation_nsga2_2020_2023.yaml` поставить
`fertility_constraints.humic_carbon.mode: disabled`.

## Установка и основной запуск

Проверено в WSL/Linux, Python 3.10.12. APSIM Next Generation
устанавливается отдельно; исходный запуск использовал сборку для .NET 8.
Из корня распакованного проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
export APSIM_MODELS="$HOME/ApsimX/bin/Release/net8.0/Models"
```

Замените путь к `Models` на свой. Основная оптимизация, запускает APSIM:

```bash
python -u scripts/run_multiyear_rotation_optimizer.py --run
```

Параметры поиска находятся в `configs/multiyear_rotation_nsga2_2020_2023.yaml`.
Результаты — `outputs/multifield/MULTIYEAR_ROTATION_NSGA2_2020_2023/`.
В конце скрипт печатает `SEND THIS ARCHIVE` с путём к архиву результатов.

## Остальные рабочие команды

Подготовить ручной пакет без запуска APSIM:

```bash
python scripts/manual_multiyear_apsim.py prepare-baseline
```

После пользовательского расчёта подготовленного `prepared/candidate.apsimx`:

```bash
python scripts/manual_multiyear_apsim.py analyse <каталог_пакета>
```

План карты севооборота без APSIM:

```bash
python scripts/plan_crop_rotation.py --config configs/rotation_planning_2019_2023.yaml
```

Другие точки входа: `scripts/run_rotation_apsim_replay.py --run` — один расчёт
выбранной карты; `scripts/evaluate_historical_replay.py --run` — историческая
проверка. `run_multifield.py` и `multifield_2023_n_diagnostic.yaml` сохранены для
отдельной старой диагностики 2023 года: нового ограничения Humic в ней нет.
`configs/multifield.yaml` — незаполненный шаблон, не основной сценарий.
Планировщик 2025–2029 строит только карты, не прогноз APSIM за будущие годы.

## Проверка и подтверждённые результаты

```bash
python -m pytest -q
```

Тесты используют синтетические данные и имитации расчётов; APSIM не запускают.
Некоторые тесты проверяют NSGA-II на синтетических функциях.
При сборке: 112 тестов пройдены, 5 тестов с синтетическим поиском не запускались;
APSIM и рабочая оптимизация не запускались. Подготовка пакета с 10 отчётами Humic проверена.
В пользовательском поиске 16.10.2026: 40 расчётов без ошибок, 35 допустимых,
5 нарушителей, 6 решений Парето. На этих 40 вариантах новый фильтр не изменил
Парето: нарушители и без него уступали другим решениям.
`examples/reference_results/` содержит сводку и 5 недоминируемых вариантов
из двух запусков, проверенных по Humic. Это примеры, не стартовая популяция.

## Состав и границы применения

`src/` — расчёты и ограничения; `scripts/` — рабочие команды;
`configs/` — сценарии; `simulation/calibrated/` — активная модель и её происхождение;
`data/` — погода, наблюдения и правила; `docs/` — исходная таблица хозяйства;
`tests/` — проверки. Контрольные суммы файлов — `RELEASE_MANIFEST.json`.

Humic не равен лабораторному гумусу. Нормативы гумуса, P, K и pH не проверяются.
Почвенный профиль, прокси культур и экономические цены ограничивают достоверность;
результаты остаются исследовательскими и не являются рекомендацией хозяйству.
Старые эксперименты, базы SQLite, окружения и сборщики документов не включены.
Для Git используется эта папка целиком; зависимости и результаты исключены `.gitignore`.
