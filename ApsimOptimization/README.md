# Многополевая APSIM-модель и оптимизация NSGA-II

Версия проекта: **2026.10.02-r1**.  
Модель: **APSIM Next Generation, calibrated-v3**.  

Реализация является промежуточной тестовой версией и не охватывает всех запланированных функций и возможностей.

Проект воспроизводит урожайность десяти полей за 2019–2023 годы и выполняет
многокритериальную оптимизацию управления полями по трём целям:

1. максимизация суммарного урожая;
2. максимизация чистой прибыли;
3. минимизация отклонения состояния почвы.

Основной интерфейс проекта — `run_multifield.py`. Однополевой оптимизатор и
старые калибровочные сценарии в релиз не включены.

## Что зафиксировано в этой версии

- Активная модель: `simulation/calibrated/full_field2019_2023_calibrated_v3.apsimx`.
- Исторический replay охватывает 37 наблюдений и десять полей.
- Для отложенного 2023 года: MAE 1,213 т/га, RMSE 1,500 т/га,
  bias −0,561 т/га, Spearman −0,297.
- Многополевой APSIM → NSGA-II проверен реальным коротким прогоном:
  17 уникальных кандидатов, 0 ошибок APSIM, 7 решений Парето.
- На каждом зерновом поле доступны 29 схем азотного питания:
  контроль без N и четыре формы N при дозах 30–210 кг действующего N/га
  с шагом 30.

## Что варьирует оптимизатор

Севооборот и культура каждого поля фиксируются историческим сценарием.

| Культура/поля | Варьируемые параметры |
|---|---|
| яровая пшеница, Field3 и Field8 | сорт Zlata/Irgina, дата посева, густота, глубина, междурядье, форма и доза N |
| овёс с подсевом многолетних трав, Field2 и Field7 | дата группы посева, густота и глубина овса, форма и доза N; параметры компонентов трав фиксированы |
| прокси озимой ржи, Field5 и Field9 | дата посева, густота, форма и доза N |
| многолетние травы, остальные поля | управление не оптимизируется |

Формы N: `UreaN`, `NH4NO3N`, `UAN_N`, `NO3N`. Удобрение вносится один раз
при посеве. Внутреннее имя поля конфигурации `dose_kg_product_ha` сохранено для
совместимости, но в активном диагностическом сценарии значение интерпретируется
как кг действующего N/га.

## Быстрый старт

Требуются Python 3.10+ и собранный APSIM Next Generation. В Ubuntu/WSL:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
export APSIM_MODELS=/home/user/ApsimX/bin/Release/net8.0/Models
bash scripts/run_project_checks.sh
```

Полный список команд, включая историческую проверку, короткий запуск
оптимизатора находится в [COMMANDS.md](COMMANDS.md).

## Основные файлы

```text
configs/       две активные конфигурации: replay и диагностическая оптимизация
data/          наблюдения, погода и экономические прокси
docs/          состояние модели, ограничения и описание версии
results/       компактные итоговые таблицы исторической проверки
scripts/       поддерживаемые сценарии запуска и проверки
simulation/    единственная активная многополевая APSIMX-модель v3
src/           код многополевой модели, оценки и NSGA-II
tests/         тесты поддерживаемой многополевой реализации
```

Каталог `outputs/` создаётся во время работы и не хранится в Git.

## Ограничения

- площади полей приняты равными приблизительно 0,2 га;
- точные цены, допустимые смеси, производственные границы удобрений и целевые
  интервалы почвенных показателей не подтверждены;
- Аргамак 2019 года представлен сортом-прокси;
- клевер с тимофеевкой представлен структурным прокси;
- совместные посевы поддерживаются, но доли компонентов смеси не оптимизируются;
- для полей «овёс с подсевом трав» целевой урожай сейчас соответствует зерну
  овса; урожай подсевных компонентов не прибавляется к этой цели;
- десять полей используют общий почвенный профиль;
- исходная влажность и период прогрева Field7/2019 неизвестны;
- систематическое недопредсказание овса полностью не устранено.

Поэтому решения Парето показывают работу вычислительной цепочки, но не являются
готовыми рекомендациями хозяйству.
