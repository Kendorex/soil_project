# Hydrology v2 — изолированная разработка

Эта папка предназначена для исправления водного блока без изменения рабочего
`simulation/standart.apsimx`.

## Правила

1. Базовая копия должна быть побайтно идентична оригиналу; её хеши записываются
   в `workspace_manifest.json`.
2. Все изменённые APSIMX-файлы создаются как отдельные кандидаты. Базовая копия
   не перезаписывается.
3. Полевые измерения хранятся отдельно от рассчитанных и унаследованных
   параметров.
4. Неизвестные `AirDry`, `LL15`, `DUL`, `SAT`, `Ks` и глубокая `BD` не
   обозначаются как измеренные.
5. Наблюдаемая УГВ используется только в явно помеченных диагностических
   вариантах. Месячным значениям нельзя приписывать точный день без записи
   допущения.
6. Нулевая урожайность после раннего водного коллапса маркируется как ошибка
   применимости гидрологии, а не как нормальный прогноз.

## Воспроизведение аудита

```bash
python3 scripts/prepare_hydrology_v2_workspace.py
python3 scripts/build_hydrology_v2_audit.py
python3 scripts/prepare_hydrology_v2_candidates.py
python3 run_optimizer.py --config configs/optimizer_config.yaml \
  --calibration-config configs/hydrology_v2_zlata_2020_2023_bd_only.yaml \
  --diagnose-cultivar-season
python3 scripts/evaluate_hydrology_v2.py
python3 scripts/prepare_hydrology_v2_ensemble.py
python3 scripts/evaluate_hydrology_v2_ensemble.py
python3 scripts/prepare_hydrology_v2_groundwater_2023.py
```

Сценарии УГВ создаются раздельно для каждого ландшафта. Они не усредняются и не
включаются по умолчанию: пользователь будущей системы должен либо выбрать
известный ландшафт, либо получить диапазон по подходящим сценариям.

## Текущий результат

Кандидат `01_measured_bd_top30` использует измеренную среднюю плотность поля 3
только в слоях 0–15 и 15–30 см, а `SAT` вычисляет из пористости. Он не считается
готовым профилем: `AirDry`, `LL15`, `DUL`, `Ks` и глубокая плотность остаются
унаследованными от австралийского примера.

`scripts/evaluate_hydrology_v2.py` отделяет технически завершившийся запуск APSIM
от пригодного прогноза. Ранний водный стресс с почти нулевым урожаем отклоняется
как `rejected_hydrology_failure`; любой расчёт с неподтверждённой кривой
водоудержания остаётся `diagnostic_only_unvalidated_soil`.

## Ограниченный ансамбль верхнего слоя

`prepare_hydrology_v2_ensemble.py` создаёт пятнадцать диагностических вариантов
верхних 30 см. `AirDry` и три гипотезы `LL15` получаются из квантилей 120
точечных измерений объёмной влажности поля 3 за 2023 год. Две гипотезы `DUL`
используют влажный хвост наблюдений и явно записанную прибавку 0,03; ещё три
значения 0,32/0,40/0,48 являются осью чувствительности внутри ограничения по
пористости, поскольку полевая влагоёмкость напрямую не измерялась. Это не
замена лабораторному определению водоудерживающей кривой: глубокий профиль и
`Ks` всё ещё унаследованы, а варианты предназначены для проверки
идентифицируемости параметров сразу по 2020–2023 годам.
