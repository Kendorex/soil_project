# Что нужно подтвердить для оптимизации сезона 2023

## Уже зафиксировано по исходным данным

- Урожайный год: 2023.
- Окно решений: 2022-09-01 — 2023-12-31; оно включает осенний посев озимой ржи.
- Размещение культур фиксировано историческим севооборотом десяти APSIM Zone.
- Наблюдаемая технология содержит варианты «без удобрений», N30, N60P60K60 и K70.
  Это описание факта, а не утверждённое пространство поиска.
- Фактическая урожайность 2023 имеется для всех десяти полей.
- Пользовательская оценка площади каждого участка: около 0,2 га; общая расчётная
  площадь десяти участков — около 2 га.
- Компоненты урожая 2023 сопоставлены с культурой каждого поля. Для овса учитывается
  зерно овса, для травосмеси — RedClover + PlantainForage.

## Значения, без которых `optimize` не запускается

1. Разрешённые товарные удобрения или смеси: название, цена за кг продукта,
   соответствующий `apsim_type`, массовая доля компонента и коэффициент перевода
   кг продукта в величину `Fertiliser.Apply`.
2. Минимальная и максимальная доза продукта на гектар по каждому полю, даты и
   глубина внесения. Наблюдаемые N30/N60/K70 не превращаются автоматически в границы.
3. Допустимые отношения доз между полями или явное `dose_ratios: []`, если таких
   ограничений нет. Соотношения компонентов внутри смесей задаются отдельно.
4. Цена реализуемой массы по каждому учитываемому продукту и коэффициент перевода
   сухой массы APSIM в товарную массу. Также нужны стоимость одного внесения и
   прочие затраты на гектар по каждому полю. Для яровой пшеницы и озимой ржи нужны
   отдельные цены, хотя внутри APSIM обе культуры используют компонент `Wheat`.
5. Показатель состояния почвы, глубина, единицы, дата или период контроля и хотя бы
   одна граница (`min`, `max` либо обе) для каждого поля.

Поскольку эти значения не предоставлены, рабочий `configs/multifield.yaml`
остаётся заблокированным для `optimize`. Для технического анализа создан отдельный
`configs/multifield_2023_n_diagnostic.yaml`; его числа являются сценарными прокси.

## Ограничение текущей APSIM-модели

Модель содержит рассчитываемые пулы NO3, NH4 и Urea, поэтому на первом рабочем
этапе можно контролировать минеральный азот. В ней нет отвечающих на внесение пулов
фосфора и калия. Чтобы оптимизировать N/P/K и остаточные P/K, сначала нужно добавить
и откалибровать соответствующие почвенные модули и удобрения в APSIMX. Значения
P2O5 и K2O из агрохимической таблицы сами по себе этого механизма не создают.

Лист `Агрохимия` не даёт полного набора итоговых почвенных измерений по всем десяти
полям за 2023 год: за 2023 представлены только точки Field1, а за 2022 — Field4 и
Field10. Поэтому единый допустимый интервал нельзя честно вычислить из этой таблицы
без отдельного агрономического правила или дополнительных анализов.
