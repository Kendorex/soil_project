# Проверка компонентов урожая овса

Лист `Фенофазы` содержит массу 1000 зёрен овса для всех исторических случаев.
Это позволяет проверять не только итоговый урожай, но и способ его формирования.

Для Yakov за 2020–2022 годы средняя наблюдаемая масса 1000 зёрен равна 35,6 г,
модельная — 14,6 г. Если исключить известный сбой жизненного цикла Field1/2021,
модель воспроизводит только 36% фактической массы зерна и формирует в среднем
в 3,54 раза больше зёрен, чем следует из наблюдаемого урожая и массы 1000
зёрен. Даже в двух случаях, где ошибка итогового урожая меньше 0,2 т/га,
модельная масса зерна составляет 12,6 г против 35,5 г, а расчётное число зёрен
завышено примерно втрое.

В 2023 году исходная модель даёт в среднем 9,49 г на 1000 зёрен против 40,5 г,
а после исправления перехода от пшеницы — 9,90 г. Следовательно, совпадение
итогового урожая в части прошлых лет было получено за счёт компенсации двух
ошибок: слишком большого числа и слишком малой массы зёрен. Такая компенсация
неустойчива для прогноза нового года.

Калибровку овса нужно оценивать одновременно по урожаю, сухой биомассе, массе
1000 зёрен и фазам развития. Настройка только по урожаю может снова получить
правильный итог неправильным механизмом.

```bash
python3 scripts/audit_oats_yield_components.py
```
