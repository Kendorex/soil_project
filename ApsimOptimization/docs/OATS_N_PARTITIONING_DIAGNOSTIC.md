# Диагностика влияния N на формирование зерна овса

Эксперимент сравнивает только две дозы, которые явно присутствуют в исходных
наблюдениях овса 2023 года: N30 и N60. Обе дозы вносятся однократно при посеве
4 мая. Тип удобрения сохраняется из менеджера APSIM. Эти значения являются
диагностическими сценариями и не задают границы будущей оптимизации.

Запуск из корня проекта в Ubuntu/WSL:

```bash
python3 scripts/diagnose_oats_n_partitioning.py --run
```

Скрипт выполняет два APSIM-прогона и сохраняет таблицы `dose_response.csv` и
`dose_deltas.csv`. В них сравниваются урожай, LAI, биомасса, азотный стресс,
число и размер зёрен, индекс урожая, спрос зерна на сухое вещество и степень его
обеспечения. В конце печатается путь `SEND THIS ARCHIVE` к компактному архиву
`oats_n_partitioning_ДАТА_ВРЕМЯ.tar.gz`.

Полученный 24 сентября расчёт завершился без ошибок APSIM. Переход от N30 к N60
увеличил расчётный урожай на 0,792 т/га для Field2 и на 0,764 т/га для Field7,
максимальный LAI — на 1,43–1,51, надземную биомассу — примерно на 271 г/м².
Главный отклик связан с увеличением числа зёрен примерно на 8 500 шт./м². Масса
одного зерна осталась около 0,009 г, а азотный стресс сохранялся во все 36 дней
налива при обеих дозах. Азот существенно влияет на результат, но интервал N30–N60
сам по себе не устраняет недобор урожая 2023 года.
