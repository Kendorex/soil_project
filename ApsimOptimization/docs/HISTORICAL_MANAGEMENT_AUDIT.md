# Аудит истории внесений 2019–2023 годов

Аудит показывает происхождение каждой дозы, используемой менеджером удобрения
при посеве. Для каждого поля и года записываются культура, дата события посева,
исходная технологическая метка, N/P/K из метки, статическая настройка APSIM и
фактически выбранный источник дозы.

Источники разделяются на три группы: подтверждённая метка N из исторической
таблицы, статическое значение APSIM при отсутствии пригодного наблюдения и год
переноса многолетней культуры без нового посева. Значения-заполнители не считаются
ошибочными автоматически, но отмечаются как неподтверждённые входы.

```bash
python3 scripts/audit_historical_management.py
```

Результат сохраняется в `outputs/multifield/HISTORICAL_MANAGEMENT_AUDIT` и в
архиве `historical_management_audit_ДАТА_ВРЕМЯ.tar.gz`. Таблица
`management_history.csv` содержит полную историю, `model_fallback_events.csv` —
только неподтверждённые события, `field_coverage.csv` — их количество по полям.
APSIM при этом не запускается, рабочая модель не изменяется.

менеджера APSIM. Для 12 событий историческая запись отсутствует, для двух метка
не содержит явного N, ещё один посев находится до начала погодного ряда.

рапс 2021 года. Field7 имеет одно такое событие — рапс 2020 года. Во всех трёх
случаях APSIM применяет статическое значение 30 NO3N. Это модельное допущение,
а не восстановленная фактическая технология.
