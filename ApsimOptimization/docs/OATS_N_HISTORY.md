# Историческая проверка предложения азота овсу

Диагностика объединяет восемь случаев овса 2019–2023 годов в таблице
`oats_n_supply_history.csv`. Для каждого случая сохранены наблюдаемый и
расчётный урожай, поглощение N, дни стресса, отношение потенциального
предложения почвенного N к текущему спросу растения и распределение N по слоям.
Период 2019–2022 обозначен как development, 2023 год — validation.

Для всех успешно рассчитанных случаев потенциальное предложение N часто ниже
текущего спроса. Однако знак ошибки урожая различается: в 2020 и 2022 годах
урожай завышен на 0,67–0,98 т/га, в 2021 и 2023 годах встречается существенное
занижение. Поэтому глобальное увеличение скорости поглощения N без совместной
проверки всех лет не является обоснованным исправлением.

Случай Field3/2019 выделяется отдельно: расчётный урожай равен нулю, наблюдаемый
сорт Аргамак представлен в модели сортом Yakov. Этот случай нельзя использовать
для настройки параметров поглощения до отдельной проверки установления и события
уборки.

Следующая итерация — диагностический экран параметров механизма предложения N.
Кандидатные значения должны быть взяты из документированных параметров APSIM и
оцениваться по двум наборам: 2019–2022 для настройки и 2023 для проверки. Ни один
вариант не переносится в рабочую модель только по улучшению 2023 года.
