# Итоговая историческая проверка

Файлы в этом каталоге скопированы из финального исторического replay от
02.10.2026. Основным вариантом выбран `control`.

- `historical_replay_evaluation.*` — полный итог и краткий отчёт;
- `decision_readiness.json` — формальные критерии готовности;
- `historical_replay_field_comparison.csv` — сравнение по полям;
- `bias_correction_evaluation.json` — отклонённая проверка эмпирической коррекции.

Тяжёлые временные APSIMX-копии, SQLite-базы, журналы и промежуточные графики
намеренно не входят в чистый релиз.
