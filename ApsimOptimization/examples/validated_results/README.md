# Контрольные результаты WSL

Здесь сохранены компактные результаты двух реальных запусков APSIMX с
обновлённым `standart.apsimx` и исправленным правилом выбора строки
`HarvestRipe`.

- `F0_no_fertilizer` — схема без удобрения;
- `F14_NH4NO3N_210` — контрольная схема F14.

Файлы предназначены только для проверки формата и сравнения поведения кода.
Это не итоговый результат оптимизации. Исходные SQLite `.db`, временные
`.apsimx` и многомегабайтные логи намеренно не включены.
