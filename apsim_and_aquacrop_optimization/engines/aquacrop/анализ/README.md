# Анализ переноса APSIM → AquaCrop

Материалы относятся к текущей конфигурации десяти полей за 2019–2023 годы: `AquaCrop_Project_apsim/configs/rotation_fixed.apsimx`, `rotation_parameters.json`, `weather_rotation.met`, базовым файлам `generated/fixed_field_*` и отдельным настроенным копиям `calibration_vniimz/generated/fixed_field_*`.

Основной вывод: календарь, погоду, густоту и водные характеристики почвы можно перенести с явным преобразованием единиц. Биологическую конфигурацию APSIM целиком скопировать в AquaCrop нельзя: модели по-разному описывают развитие, полог, накопление биомассы, питание и смесь видов. Сам факт создания .CRO с названием сорта не означает переноса его физиологии.

## Как понимать статус переноса

| Статус | Значение |
| --- | --- |
| Прямой | Та же физическая величина с изменением формата/единиц. Это не обещание совпадения результатов моделей. |
| Производный | Нужен расчёт, восстановление по временным рядам или согласование определений. |
| Приближение | В переносе использована заменяющая модель, шаблон или допущение. |
| Отдельный вход AquaCrop | Нужен свой параметр AquaCrop; прямого эквивалента в текущем извлечении APSIM нет. |
| Не воспроизводится | Соответствующий процесс APSIM не перенесён текущим адаптером. |

В отчёте различаются «можно извлечь», «уже переносится» и «не найдено в явном файле». APSIM может загружать параметры вида из ресурсов установленной сборки: отсутствие значения в .apsimx не доказывает его отсутствие в APSIM.

## Границы анализа

Анализ выполнен по локальной конфигурации и коду её переноса, а не по абстрактному перечню возможностей всех версий APSIM/AquaCrop. Поддержка ядром процесса не означает, что его настроил текущий адаптер. Для полного извлечения скрытых стандартных параметров APSIM потребуется экспорт развёрнутой модели из той же сборки APSIM, которой выполнен расчёт.

Созданы только материалы в этой папке. Ядро, почва, исходные .CRO, конфигурация APSIM, наблюдения Excel и результаты симуляций этим анализом не изменяются. Перезапуск симуляций для составления справочника не требуется.

Обновить автоматически извлекаемые справочники и снимок после изменения входов:

```powershell
python -B анализ/build_analysis.py
```

Скрипт обновляет файлы 03–05 и inventory.json. Пояснения 01–02 требуют ручной проверки при изменении логики переноса.
