## Связь APSIM и PINN

```text
Платформа → Python-компонент → APSIM
                  ↕              ↕
                 PINN ← данные почвы и погоды
                  ↓
           прогноз влажности → обратно в APSIM
```


Каждый день расчёта:

1. APSIM передаёт Python состояние почвы, осадки и потенциальное испарение.
2. PINN использует влажность с конца предыдущего дня, параметры слоёв и историю осадков/испарения, чтобы предсказать новую влажность.
3. Python переводит прогноз влажности в потенциал воды `PSI` и записывает его в APSIM.
4. APSIM продолжает расчёт с обновлённым состоянием.

Обмен идёт через **ZeroMQ по TCP**. В режиме `replace` прогноз влияет на APSIM. В режиме `compare` прогноз только сохраняется для сравнения. Сам водный расчёт APSIM выполняется в обоих режимах.

## Что загрузить и установить

**Загрузить папку `bmi_apsim_pinn` с кодом и ресурсами:**

| Файл или папка | Для чего нужен |
|---|---|
| `src/` и `pyproject.toml` | Python-компонент и его зависимости. |
| `config/bmi_config.json` | Настройки запуска и пути к файлам. |
| `config/test_field_2021.apsimx` | Модель APSIM с кодом обмена `Synchroniser`. |
| `weather/weather_2021_normalized.met` | Погода для расчёта. |
| `pi_deeponet_swim3_mvp.pth` | Обученная нейросеть, её настройки и параметры нормализации. |

**Отдельно установить APSIM Next Generation и Python 3.10–3.11.** Из папки компонента установить Python-зависимости:

```bash
python -m pip install -e .
```

## Что настроить перед запуском

В `config/bmi_config.json` указать:

| Настройка | Что указать |
|---|---|
| `apsimx` | Путь к модели `.apsimx`. |
| `model` | Путь к обученной модели `.pth`. |
| `weather_met` | Путь к погоде `.met`. |
| `out_dir` | Каталог с правом записи для результатов. |
| `mode` | `replace` для расчёта с обратной связью или `compare` для сравнения. |
| `apsim_mode` | `windows` или `wsl`. |
| `apsim_windows_bin` | Путь к `Models.exe` для Windows. |
| `apsim_wsl` | Дистрибутив, пользователь и путь к APSIM для WSL. |

**Модель APSIM и checkpoint должны быть совместимы.** Поставляемая модель содержит семь слоёв почвы. Число слоёв должно совпадать с настройками нейросети. В другой `.apsimx` необходимо сохранить совместимый Manager `Synchroniser`: обычный файл APSIM без него не подключится к Python.

## Как платформа запускает компонент

Точка входа — **`src.bmi_apsim_pinn.BmiApsimPinn`**. Она предоставляет BMI — интерфейс с методами запуска, обновления, чтения данных и завершения:

```python
from src.bmi_apsim_pinn import BmiApsimPinn

model = BmiApsimPinn()
try:
    model.initialize("config/bmi_config.json")
    while model.get_current_time() < model.get_end_time():
        model.update()
        sw = model.get_value("pinn_soil_water_volumetric")
finally:
    model.finalize()
```

## Какие результаты забирать

| Результат через `get_value()` | Содержание и единицы |
|---|---|
| `pinn_soil_water_volumetric` | Прогноз влажности PINN по слоям, объёмная доля воды. |
| `soil_water_volumetric` | Влажность APSIM перед текущей корректировкой, объёмная доля воды. |
| `soil_psi_read` | Потенциал воды, прочитанный из APSIM после записи в режиме `replace`, мм. |
| `pinn_q_top`, `pinn_q_bottom` | Прогноз верхнего и нижнего водного потока, м/сутки. |
| `pinn_runoff`, `pinn_evap_actual`, `pinn_sink_total` | Прогноз стока, испарения и суммарного поглощения, м/сутки. |
| `pinn_pond_depth` | Прогноз глубины воды на поверхности, м. |
| `date` | Дата расчёта в формате `YYYYMMDD`. |

Значения возвращаются как NumPy-массивы: профиль — по числу слоёв, одиночный показатель — массив из одного элемента. Потоки PINN доступны как результаты; обратно в APSIM записывается только `PSI`, рассчитанный из прогноза влажности.

После расчёта сохраняются CSV истории `pinn_run_<дата>_<время>.csv`, лог `apsim_stdout.log`, рабочая копия `.apsimx` и результаты самого APSIM. Для платформы CSV содержит историю по дням, а `get_value()` — последнее доступное состояние.
