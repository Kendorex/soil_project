# Финальные результаты калибровки сортов

Здесь сохранён компактный проверенный набор результатов для `Zlata` и
`Irgina`, который используется скриптом
`scripts/build_cultivar_calibration_report.py`.

Рабочие APSIMX-копии, SQLite-базы и промежуточные поисковые каталоги сюда не
входят. Новые расчёты должны записываться в `outputs/`, а не изменять этот
эталонный набор автоматически.
