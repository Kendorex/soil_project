# Решение по дальнейшей доработке модели овса

Диагностический цикл отделил три механизма. Уточнение даты уборки пшеницы и
вывоз свежей соломы улучшили RMSE урожая овса 2023 года с 2,236 до 1,420 т/га
и RMSE сухой биомассы с 171,67 до 69,26 г/м². Этот эффект физически локален,
но фактическая доля вывоза соломы неизвестна, поэтому сценарий пока нельзя
перенести в рабочую модель.

Усиление фотосинтеза не решило проблему. При полном снятии его реакции на
N-стресс фотосинтез во время налива вырос на 78–80%, однако урожай и масса зерна
снизились из-за ограничения фактического распределения сухого вещества азотом.
Следовательно, один углеродный источник не определяет ошибку.

Численная верхняя граница с `MinimumNConc=1e-6` показала, что N-ограничение
сильно влияет на величину урожая 2023 года: RMSE снизилась с 1,420 до
0,351 т/га. Одновременно RMSE 2020–2022 выросла с 1,391 до 2,289 т/га. Масса
зерна увеличилась только до 18,6 мг на Field2 и 15,8 мг на Field7 при
наблюдаемых 39,6 и 41,4 мг. Число зёрен осталось завышенным. Значение
`MinimumNConc=1e-6` физиологически невозможно, поэтому улучшение урожая не
является калибровочным результатом.

Глобальные изменения `MinimumNConc`, реакции фотосинтеза на N и одного
`GrainsPerGramOfStem` отклонены. Они либо ухудшают переносимость между годами,
либо сохраняют неверные компоненты урожая. Рабочая APSIMX-модель остаётся без
этих изменений.

Совместная проверка уточнила этот вывод. Медианное значение
`GrainsPerGramOfStem=12,2002`, полученное только по 2020–2022 годам, снизило
ошибку массы 1000 зёрен и числа зёрен примерно в несколько раз как на данных
разработки, так и в 2023 году. При этом ошибка урожая 2023 года выросла до
1,791 т/га. Совместно с невозможным N-пределом масса зерна приблизилась к
наблюдениям, но урожай и переносимость между годами одновременно не улучшились.
Это подтверждает, что один постоянный коэффициент зернообразования не описывает
наблюдаемую межгодовую изменчивость.

Дальнейшая разработка разделяется на два направления. Неизвестное управление
остатками и начальное состояние N представляются воспроизводимыми сценариями
неопределённости. Структурная ошибка формирования зерна оценивается отдельно по
урожаю, сухой биомассе, массе 1000 зёрен и выведенному из неё числу зёрен.
Любое изменение принимается только при улучшении данных разработки 2020–2022 и
независимой проверки 2023 года. После этого оптимизатор должен использовать не
один детерминированный прогноз, а урожай и состояние почвы по нескольким
допустимым сценариям с явным показателем неопределённости.
