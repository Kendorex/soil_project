# Проверка фенологии овса

Эксперимент сравнивает текущую фенологию Yakov с полными фенологическими
профилями Drummond и Milton из установленного ресурса APSIM
`Models/Resources/Oats.json`. Используются только точные наборы параметров;
промежуточные значения и диапазоны не вводятся. Параметры листьев и зерна Yakov
во всех вариантах сохраняются.

```bash
python3 scripts/screen_oats_phenology_profiles.py --run
```

Варианты оцениваются отдельно по RMSE урожая, MAE даты кущения и MAE даты
колошения. Метрики не нормируются и не складываются с весами. Для разработки
используются наблюдения Yakov 2020–2022 годов, 2023 год остаётся проверочным.
Случай Аргамак 2019 года выводится отдельно из-за другого сорта и ранее
подтверждённого раннего водного ограничения. Рабочий APSIMX автоматически не
изменяется. Для анализа нужно передать архив
`oats_phenology_screen_ДАТА_ВРЕМЯ.tar.gz`.

Контрольный расчёт 24 сентября показал, что текущий Yakov доминирует оба
эталонных профиля по всем трём метрикам разработки. Для Yakov RMSE урожая равен
1,391 т/га, MAE кущения 4,2 дня, MAE колошения 7,8 дня. Для Drummond получены
1,573 т/га, 19,0 и 12,8 дня; для Milton — 1,923 т/га, 39,8 и 29,7 дня.
Drummond немного уменьшил RMSE 2023 года с 2,236 до 2,152 т/га, но ценой заметно
худшей фенологии и худшего результата 2020–2022 годов. Поэтому ни один профиль
не принимается, рабочая модель остаётся без изменений. Следующая проверка должна
разделить параметры этих профилей и оценить их по одному: полный перенос сорта
скрывает действие отдельных фазовых параметров.
