# Диагностика физиологии овса

Диагностика предназначена для поиска причины недооценки урожая овса на Field2 и
Field7 в 2023 году. Она не изменяет рабочую калиброванную модель и не подбирает
дозы удобрений. Временный сценарий воспроизводит известные исторические метки N
однократно при посеве; тип удобрения сохраняется из APSIMX, а P/K не моделируются.

Запуск из корня проекта в Ubuntu/WSL:

```bash
python3 scripts/diagnose_oats_physiology.py --run
```

Если APSIM установлен в другом месте:

```bash
APSIM_MODELS=/полный/путь/к/Models python3 scripts/diagnose_oats_physiology.py --run
```

Скрипт печатает строку `SEND THIS ARCHIVE`. Указанный архив
`oats_physiology_ДАТА_ВРЕМЯ.tar.gz` содержит суточные показатели, сводку по
полям, схему фактически полученных колонок APSIM, историческое сравнение и
provenance входных файлов. Для анализа достаточно передать этот архив.
